Step 1

Connect Cloudflare

Sign in with Cloudflare so the wizard can find your account and check it is ready. The login is read-only — it cannot change anything.

Running a fork? The preconfigured login belongs to the original owner's Cloudflare account. Register your own client (README: “enable Cloudflare login”), or continue with a token in Step 2 — setup works fully either way.

Login is not configured for this copy of the wizard yet. It takes a minute, once:

  1. In Cloudflare open Manage account → OAuth clients → Create client and name it Runner Vault Setup Wizard.
  2. Choose a public client, token authentication None (PKCE), with the grants Authorization Code and Refresh Token; set the redirect URL to
  3. Allow the scopes Account Settings: Read, D1: Read and Workers: Content Read-Only (there is no scope literally named “Workers Scripts” — that one is the Workers read scope; offline_access is added automatically with the Refresh Token grant).
  4. Put your client ID in docs/wizard-config.json in this repository and reload this page.
