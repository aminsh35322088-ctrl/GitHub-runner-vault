Runner Vault — one-click setup

This wizard deploys your credential vault to Cloudflare through GitHub Actions. You only make one token and paste it once — everything else is automatic.

One-time prerequisite: in your repository, open Settings → Pages, choose Deploy from a branch, then select branch main and folder /docs. Save and reopen this page after GitHub Pages publishes it.

Your repository

Use the account and repository that hold (or will hold) your vault fork. Every link below follows these two fields.

Step 1 — Create your Cloudflare token

Everything is pre-selected — just press Create Token and copy the value.

Create the token on Cloudflare

Step 2 — Check the token

Paste the token to verify it here, in your browser, before saving it anywhere.

    Step 3 — Save it as a repository secret

    Open the prefilled secret form on GitHub and paste the same token as CLOUDFLARE_API_TOKEN.

    Save CLOUDFLARE_API_TOKEN

    If the token check above lists more than one Cloudflare account, also save the ID of the account you want to deploy into as CLOUDFLARE_ACCOUNT_ID. This second secret is optional when exactly one account is visible to the token.

    Optional: set CLOUDFLARE_ACCOUNT_ID

    Step 4 — Deploy

    Run the Deploy to Cloudflare workflow once. After that, merges to main that change the Worker app, client, or root pnpm manifests redeploy automatically. Documentation-only changes do not need a Worker deployment.

    Open the Deploy workflow

    Security: this page is open source (it lives in the vault repository under docs/). Your token stays in this page's memory only — it is never stored and is sent nowhere except Cloudflare's own API when you press “Check token”. You can revoke or rotate the token any time in the Cloudflare dashboard.
